# MIS-Teach Knowledge Graph synthetic examples

All files in this directory are invented, non-copyrighted documentation fixtures:

- `demo_concepts.json` — Concept-node shape.
- `demo_chunks.json` — Chunk-node shape.
- `demo_relationships.json` — Relationship shape.
- `demo_graph_query.json` — Query and expected response shape.

They are not a textbook, registry, Neo4j dump, or complete import contract.

This package intentionally contains no textbook PDF, global concept registry, Neo4j export,
embedding, or generated graph JSON. Those materials are excluded because their licence and data
provenance must be reviewed by each deployer.

Use the synthetic `sample_graphrag_result.json` in the repository-root `examples/` folder only to
understand the public response shape. It is not a graph-building input.
